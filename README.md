# Purrjury

A daily logic puzzle about lying cats.

Play it here: [yusufsocal.github.io/Purrjury](https://yusufsocal.github.io/Purrjury/)

## The game

You get a grid of cats. Every cat is either **honest** or a **liar**: honest cats always tell the truth, liars always lie. Each cat says one thing, for example:

- "Felix is a liar."
- "Exactly 2 of the cats in row 3 are liars."
- "Doodle and Hobbes are both honest, or both liars."

Find out which cats are lying. Every puzzle has exactly one answer, and you can always reach it with logic alone, no guessing.

There's a new 3x3 and 4x4 puzzle every day.

## How to play

- One cat is already solved for you. Start with its clue.
- Tap a cat to mark it honest, tap again for liar, once more to clear it.
- Once every cat is marked, press **Submit**.
- Stuck? **Hint** shows a clue that can find a new cat right now.
- Right click or long-press a cat to see which cats talk about it.
